# CS77 human access

**World ID 4.0 — One Human, One Claim**

CS77 human access is an experimental demonstration of human uniqueness and one-human-one-claim enforcement using World ID 4.0.

## Objective

Demonstrate how a verified human can obtain access to a digital resource while preventing the same human from claiming access more than once.

## Architecture

The system is organized into three independent components:

- **human-verification** — verifies World ID proofs.
- **cs77-human-interface** — provides the user-facing access interface.
- **cs77-human-counter** — displays public access metrics.

## Core principles

- One human, one claim.
- Privacy-preserving verification.
- No public disclosure of personal identity.
- Independent and clearly separated components.
